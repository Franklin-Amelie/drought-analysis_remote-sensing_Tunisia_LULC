# drought-analysis_remote-sensing_Tunisia_LULC
Assessment of vegetation dynamics &amp; drought sensitivity of olive trees, natural forest and pure stands in northern Tunisia, using Sentinel-2-derived SAVI &amp; NDMI (2017–2026). Vegetation index anomalies were correlated with the SPEI (drought index), using Spearman rank corr., cross-corr. analysis, Kruskal-Wallis tests, and other.
